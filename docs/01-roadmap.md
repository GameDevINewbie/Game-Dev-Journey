# 01 - Game Development Roadmap

> A complete roadmap documenting my journey from beginner to professional game developer.

My long-term goal is to become a professional game developer capable of designing, developing, publishing, and maintaining commercial-quality games using modern development practices and AI-assisted workflows.

This repository serves as my personal Game Development Wiki, containing everything I learn throughout this journey.

- Build polished commercial games
- Publish games on Steam
- Publish games on Android
- Learn industry-standard workflows
- Understand complete game development lifecycle

# Success Criteria

I will consider this roadmap successful when I can:

- Design a game from an idea.
- Plan the project structure.
- Implement gameplay mechanics.
- Create polished user interfaces.
- Optimize performance.
- Publish games on multiple platforms.
- Maintain released games.
- Continue learning and improving through future projects.

---

# Guiding Principles

- Learn by building.
- Keep projects small and iterative.
- Write clean, maintainable code.
- Use Git from day one.
- Read official documentation.
- Use AI to accelerate learning, not replace understanding.
- Finish projects instead of abandoning them.
- Prioritize consistency over perfection.
