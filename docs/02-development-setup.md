# Version Control

- Commit frequently
- Use meaningful commit messages
- Push regularly
- Create branches for major features
- Keep `main` stable

---

# Coding Principles

- Keep code simple
- Write reusable code
- Comment only when necessary
- Use consistent naming
- Refactor regularly
