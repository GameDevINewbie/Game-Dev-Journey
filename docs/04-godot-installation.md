# 04 - Godot Installation

> Quick guide to install and set up Godot.

---

# Download

Download the latest **Stable** version from the official Godot website.

Choose:

- Standard (Recommended)
- .NET (Only if using C#)

---

# Installation

## Windows

1. Download Godot.
2. Extract (if ZIP).
3. Run `Godot.exe`.

## Linux

```bash
chmod +x Godot
./Godot
```

Or install using your package manager if preferred.

---

# First Launch

- Create a new project.
- Select project location.
- Choose **Forward+** or **Compatibility** renderer.
- Click **Create & Edit**.

---

# Recommended Settings

- Enable Autosave.
- Enable V-Sync.
- Set Editor Theme (Optional).
- Install Export Templates.

---

# Verify Installation

- Open Godot.
- Create a sample project.
- Run the project (`F5`).

If the project runs successfully, the installation is complete.

---

# Update

- Download the latest stable version.
- Replace the old executable.
- Open existing projects with the new version.

---

# Troubleshooting

- Verify GPU drivers are updated.
- Ensure Export Templates are installed.
- Check the official documentation for version-specific issues.

---

> Recommendation: Use the latest **Stable Standard** version unless you specifically need C# support.
