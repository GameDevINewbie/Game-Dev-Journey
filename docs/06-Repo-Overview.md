# 🎮 Game Development Journey

> My journey from beginner to professional game developer using **Godot**, **Git**, **AI**, and modern software engineering practices.

---

## 📖 About

This repository serves as my personal **Game Development Wiki**, documenting everything I learn while building commercial-quality games.

It includes:

- 📚 Learning notes
- 🛠 Development environment setup
- 🎮 Game development projects
- 📖 Godot documentation
- 💻 Git & GitHub workflow
- 🤖 AI-assisted development
- 🧠 Game design concepts
- 🚀 Publishing guides
- 📝 Personal development logs

The goal is to have a single repository containing all the knowledge, documentation, and projects needed throughout my game development journey.
